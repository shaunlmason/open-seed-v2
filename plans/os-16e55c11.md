# os-16e55c11 — Phase 12 item 6: docs generation, the operator handbook, and simulation mode

Build plan Phase 12 item 6: docs generation (lifecycle prose from
`transitions.json`; the operator handbook) and simulation mode
(credential-free end to end), which the Phase 10 exit record names as
III.O row 5's second half — the seam where a decider plugs into the
trajectory-prefix harness. Charter III.Q row 3 ("docs are governed:
operator handbook, generated worker docs, stamped design docs"), §II.16
("Simulation mode: the whole system runs end-to-end against synthetic
intents with mock executors and zero credentials"), III.O row 5, and
III.R row 7 (a team that has never spoken to the authors adopts from
the README in under an hour) as the bar the handbook is written
against. Phase 12's exit line also asks that "the fixture organization
runs a week-long simulated backlog (accelerated clock) meeting III.R's
zero-violation bar", a criterion no item owns; simulation mode is the
only place it can run, so this card takes it and says so.

## What the tree actually shows

- **The lifecycle is data, and its prose is hand-written beside it.**
  `next/spec/transitions.json` (states, transitions with `from`/`to`,
  `exclusive`), `transition.Default()` and the capability lanes
  (`keyring.AcceptedCapabilities`, the normative table in `actors.md`)
  are the sources; `lifecycle.md` and `actors.md` restate them in prose
  that nothing checks against the tables.
- **Worker docs already resolve.** `lane.Resolve(dir, manifest)`
  renders a manifest's ordered fragments into one document; `seed lane
  show` prints it. What is missing is the committed, drift-checked
  output and the operator's book around it.
- **The exit-code table is hand-kept.** `envelope.md`'s table and the
  refinement table are prose beside `envelope.Exit*` constants; the
  Phase 9 exit learned that hand-listed counts drift.
- **The loop is programmable, and its work is a function.**
  `loop.New(manifest, verbs, posture, key, work)` drives poll → orient
  → act with `Work` (`WorkFunc(subject, situation) (int, error)`) as the
  one seam where a lane does its job; the modes fixtures (#207)
  provision every lane and role from the shipped manifests and run the
  full loop wakeless against a remote — but as Go tests, with fixture
  identities and fixture work, not as a mode an operator can run.
- **The executor is an interface with one implementation.**
  `executor.Adapter` (methods `Provision`, `Wake`, `Tuple`) and
  `executor.Run` (methods `Workspace`, `Tuple`, `Meter`, …) are
  interfaces; `executor.LocalWorktree` is the only implementation and
  `seed run start` selects it by name.
- **The trajectory harness replays frames, not deciders.** #239
  records a lane's decision points at the frames it decided from and
  replays them against the configuration; `trajectories.md` states the
  residual — no decider re-runs at a point — and names simulation mode
  as the seam.
- **Instants are already declared inputs.** Expiry, spot-checks,
  lesson staleness and the report take `--as-of`/`--now`; nothing in
  admission reads a clock. That is what makes an accelerated clock a
  parameter rather than a lie.

## Design decisions (binding for this task)

**D1. `seed docs generate` renders from the tables, and `docs check`
refuses drift.** Output under `next/docs/generated/`: `lifecycle.md`
(states, every transition by verb with its `from`, `to`, exclusivity
and accepted capabilities, in the table's order), `capabilities.md`
(verb → accepted capability set from the keyring's table, with the
no-fallback rows marked), `exit-codes.md` (from the `envelope`
constants and the refinement registry), and `lanes/<lane>.md` (each
manifest resolved through `lane.Resolve`, the worker docs). The
generated files are committed; `seed docs check` regenerates into a
temp dir and diffs, exit 0 or `docs_drift` (a refinement of exit 28
`drift`, the code #244 allocates), and `make check-next` runs it, so the prose can never disagree with the table
it came from. The hand-written specs keep their explanations and gain
one line each pointing at the generated table as the authority for
the enumerations. The capability document reads one exported
enumeration — `admit.CatalogVerbs()`, derived from `affordanceCatalog`
(the var whose completeness against the spec table the lanes suite
already pins both ways), paired with the exported
`keyring.AcceptedCapabilities(verb)` (an empty accepted set is
standing-only) — so the affordance computation and the docs read the
same verb list and cannot diverge. Refused: generating from the prose;
a second hand-kept verb list; a generator
whose output is not committed (a doc nobody can read on the forge is
not a doc).

**D2. The handbook is written for the III.R adopter, and it is
checked.** `next/docs/handbook.md`: install (the pinned engine, one
command, no account), init with a preseed (item 4), the three postures
and each one's consequence quoted verbatim from what `seed doctor`
prints for it (`posture.Consequence` for cooperative; the endpoint,
identity and ledger-ref report for forge-hosted, per #244), enrolling actors and
what `kind` is and is not, the lanes and the one read each orients
from (linking the generated worker docs), the loop and its deliberate
exits, escalation, maintenance, the drills and what each proves, the
doctor, migration (item 5's two commands), and simulation mode. Every
command in it is a fenced block, and a drill runs each against the
fixture deployment under `--help` or in simulation, so a renamed flag
fails the handbook rather than the reader. Refused: a handbook that
restates the charter — it says what to type and what will happen.

**D3. Simulation mode is a verb: `seed simulate`.** `seed simulate
--config seed.json --intents <n> --seed <s> --out <dir> [--days <d>]`:
builds a throwaway deployment in a temp dir under the declared posture
(a bare remote with the `seed-admit` hook installed for
`enforced-self-hosted`; a local ledger otherwise), enrolls one identity
per shipped lane and role from the manifests as the modes fixtures do,
files `n` synthetic intents drawn by seed from a small catalog of
fixture repositories with known solutions (the evals' `fix-the-check`
shape: a red check and the patch that greens it), and runs every lane's
loop through `loop.Driver` with a **scripted decider** supplying
`Work`: the dispatcher specifies from the intent's declared acceptance,
the planner writes the plan the fixture ships, the implementer applies
the known patch, the verifier renders through the real receipt
machinery, the supervisor publishes offers and reserves budgets, the
observer records the merge a local `git merge` into the fixture's
default branch performs, the curator proposes from what recurs,
maintenance runs its pass. The executor is `executor.Mock` (new): a
temp workspace, synthetic metered usage, the declared tuple. Zero
credentials: no forge, no model, no network. The output is the
report, the reconciliation result and one summary envelope. Refused:
a simulation that calls a model or a forge; a decider that reads
anything but the frame the loop hands it.

**D4. The decider is the trajectory harness's missing half.**
`internal/decider` (new): `Decider` is one function from a
`trajectory.Frame` and a manifest to an act, and the scripted decider
D3 uses implements it. `seed trajectory replay --decider scripted`
re-runs the decider at every recorded point and reports
`choice_diverged` (a new class beside #239's five: the configuration
still presents the frame and permits the act, but the decider now
chooses differently), which is the behavioral regression III.O row 5
asked the harness to catch and #239 said it could not. The corpus under
`next/trajectories/lanes` is re-recorded from the simulation so the
recorded choices are the scripted decider's own. Refused: a decider
seam that only a model could implement — the scripted one is the
reference implementation and a model-backed one is a later adapter.

**D5. The week-long backlog runs on an accelerated clock, and the bar
is audited, not asserted.** `--days 7` advances a declared simulation
instant through seven days of ticks (the tick length declared), passing
it as `--now`/`--as-of` to every clock-reading surface (offer expiry,
spot-checks, lesson staleness, the report) while admission reads no
clock at all; intents arrive on a seeded schedule, some contracts are
parked, escalated, reaped and retired along the way. At the end the
simulation audits III.R's bar from the ledger alone: zero chain
violations (`ledger verify` green and the reconciliation clean), zero
lost updates (every admitted append present at the tip), zero silent
abandonments (every `in_progress` window ended by one of the four
deliberate exits), zero guardrail breaches (no refusal followed by a
blind retry; every claim within its ceiling once item 4 lands), zero
unreserved spend (every `run.started` inside an admitted reservation).
The audit is a named drill in CI at a size CI can afford (the tick
count declared in the drill), and the same verb at full size is what
the Phase 12 exit record cites. Refused: an audit that reads the
simulation's own bookkeeping — the ledger alone reconstructs and
justifies everything, or the bar is not met.

**D6. Bounds.** The docs generator covers the four enumerations above;
design docs are "stamped" by the plan reference every spec already
carries, and no generator touches them. The catalog of synthetic
intents is small and shipped; a deployment adds its own. `executor.Mock`
is a simulation adapter, not the container or cloud adapter Phase 13
owns. `choice_diverged` is the simulation decider's class; a
model-backed decider is Phase 13's simulation completion if it is ever
wanted.

## Acceptance Criteria

**Boundary set (new, shown working):**

1. **Generated docs cannot drift.** The four generated documents are
   committed; `docs check` passes on `main` and fails `docs_drift` on
   a planted table change or a hand edit; `make check-next` runs it.
2. **The handbook's commands run.** Every fenced command in the
   handbook is exercised by the drill; a renamed flag fails it.
3. **Simulation reaches done, credential-free.** `seed simulate` with
   a small `n` under both `enforced-self-hosted` and `cooperative`
   drives every synthetic intent to `done` through the real lanes,
   verbs and verifier, with no network, no forge and no model, and
   prints the report and the summary; a run with the network
   namespace or `HOME` denied behaves the same.
4. **The decider re-runs.** `trajectory replay --decider scripted`
   passes on the re-recorded corpus and reports `choice_diverged` on a
   planted decider change while #239's five classes stay green — the
   configuration unchanged, the choice changed.
5. **The seven-day audit.** The accelerated run at CI size ends with
   every bar at zero from the ledger alone; each bar's violation,
   planted once, is caught by name.
6. **Mutation evidence.** Each fails a drill: generating from prose;
   an uncommitted generator output; a simulation calling the network;
   the decider reading outside the frame; the audit reading the
   simulation's bookkeeping; admission reading the simulated clock.
7. `make check` green with coverage measured cold, three readings above
   the gate; the suites pass unprivileged; no model identifiers in any
   committed artifact.

**Retention set (existing, shown unharmed):**

- Every existing drill passes unchanged; the modes fixtures still
  provision from the shipped manifests and are not rewritten over the
  simulation (they stay the fixed-scenario proof; simulation is the
  seeded one).
- No new verb, transition row, capability or protocol version; every
  pre-existing chain verifies byte for byte; the trajectory corpus's
  five existing classes still fail on their planted rows.
- `seed run start` still selects `LocalWorktree` by default.
